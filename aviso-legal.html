2. Objeto del servicio

Peonia es una aplicación móvil (disponible para iOS y Android) que permite a los usuarios controlar y automatizar el riego de plantas domésticas mediante dispositivos de hardware IoT (microcontroladores ESP32) conectados a su red WiFi.

El servicio comprende:

  • La aplicación móvil Peonia (cliente Flutter para iOS y Android)
  • El servidor backend que procesa las comunicaciones entre la app y los dispositivos físicos
  • El sistema de notificaciones push para alertas relacionadas con el estado del riego
  • La interfaz de configuración de reglas de riego automático
